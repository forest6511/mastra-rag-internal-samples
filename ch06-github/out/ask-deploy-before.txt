本番環境へのデプロイ手順は、資料上では次の2種類があります。[1][2]

- **2025-06-10 の Confluence 手順**では、踏み台サーバーに SSH でログインし、`/opt/kanade-yoyaku` に移動して `./deploy.sh production` を実行し、`/healthz` が 200 を返すことを確認し、`#dev` に完了を投稿します。[1]
- **2026-09-01 の README**では、**2026-09-01 の本番切替から**デプロイは GitHub Actions で行い、踏み台サーバーの `deploy.sh` は廃止されたとあります。[2]

したがって、**新しい手順は GitHub Actions を使う方法**で、**古い踏み台サーバー経由の手順は廃止前のもの**です。[2]
