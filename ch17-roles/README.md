# 第17章 役割別の使い方と成果物

新人・開発・PM・営業・サポート・管理職が、それぞれの仕事でどう頼めば使える答えが返るかを、10の依頼文で見ます。依頼文は「誰が・何を・どの形で」の3つを書く型にそろえ、利用状況（質問ログ）の見方も扱います。

## この章で要るもの

- Node.js（記録した答えで動かす場合は、DB も API キーも要りません）
- 費用: 10の依頼文を1回ずつ聞くと、OpenAI の API で約10円。記録した答えで動かす場合は、費用はかかりません

## この章で使うファイル

- `roles.yml` — 役割ごとの依頼文（`role`・`user`・`ask`）。自社の依頼文の一覧を作るときのひな形
- `src/roles.ts` — 依頼文を順に聞き、役割ごとに答えを出す（`npm run roles`）
- `src/usage.ts` — 質問ログから利用状況を集計する（`npm run usage`）
- `out/roles.txt`・`out/usage.txt` — 書籍に載せた結果

## 手順

```bash
cd ../ch17-roles
npm ci --ignore-scripts
OFFLINE=1 npm run roles        # 記録した答えで、10の依頼文を全部聞く
OFFLINE=1 npm run roles -- 営業  # 役割を1つだけ聞く
npm run usage                  # 質問ログから利用状況を数える
```

`npm run usage` は、第14章のボットの質問ログ（`logs/questions.jsonl`）から、人ごとの数・よく材料になった資料・評価セットにまだ無い質問を数えます。

自分の依頼文を試すときは、`roles.yml` に足し、`cp ../ch16-aws/.env .env` で `.env` を用意して、`OFFLINE=1` を付けずに `npm run roles` を打ちます（DB は第4章のもの。OpenAI の API キーが要ります）。

## 確かめ方

- 結果が `out/roles.txt` と同じになる
- 答えの出典を開いて、答えの根拠を確かめる（書籍「出典の確かめ方」）。お客様に出す文や会議の資料は、そのまま使わず人が確かめる

## キー無しで確かめる

アカウントや API キーが無くても、この章のテストは回ります。記録した答えだけで、役割ごとの依頼文の答えを確かめます。DB も費用も要りません。

```bash
npm test
```

書籍に載せた実行結果は `out/` にあります。

## 後片付け

この章で新しく作るリソースはありません。`npm run roles` は、`logs/questions.jsonl` に質問を残します。試し終わったら、このファイルを消します。`roles.yml` に社員の名前など社内の情報を書いた場合は、git に入れないでください。
